公开前的最低标准

一个工具上线前，必须回答六个问题。

工具不是替代业务判断的捷径，而是让判断更高效、更容易复查的一部分。

  1. 01 / PROBLEM

    为谁解决问题

    面向哪些运营角色？在什么工作场景中使用？

  2. 02 / INPUT

    需要什么输入

    需要哪些信息或权限？由谁提供、如何获取？

  3. 03 / OUTPUT

    输出什么

    输出哪些内容？如何呈现，并怎样用于下一步判断？

  4. 04 / VERIFY

    如何验证

    如何验证方法与结果？通过哪些标准判断有效？

  5. 05 / DATA

    数据如何处理

    使用哪些数据？如何存储、隔离、删除与授权？

  6. 06 / UPDATE

    如何持续更新

    何时更新？依据什么反馈？怎样公开重要变化？

常见问题

关于未来工具库与现有起步资料。

为什么目前没有公开的自研工具？

工具需要先明确问题、输入输出、验证方式和数据边界。当前还没有达到公开标准的工具，因此保留 BUILDING 空状态。

起步资料和未来自研工具有什么区别？

起步资料是当前页面内可使用的自检、复盘模板和上线清单，不作为工具产品。未来自研工具达到公开标准后，才会进入上方工具库。

未来计划覆盖哪些工作方向？

目前只说明 B2B 平台运营与独立站 SEO/GEO 两类方向规划；具体工具名称、能力和公开时间以实际完成状态为准。

工具会保存输入的数据吗？

不能对尚未发布的工具预先作统一说明。每个真实工具公开时，会单独说明数据是否存储、如何处理以及涉及哪些外部服务。

如何了解工具建设进展？

只有达到公开标准的内容才会进入工具库；方法变化、判断依据和后续说明会通过运营笔记持续记录。
